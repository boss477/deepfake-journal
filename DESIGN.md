# Deepfake Journal — product design

The repository is currently empty, so this is the starting product brief.

Product promise: **a calm, evidence-first workspace for understanding synthetic media.**

First screen: media intake, provenance timeline, model signals, human review notes, and a confidence summary. Never present a detector score as proof. Use cyan for observed metadata, amber for uncertain signals, and green only for independently verified evidence.

Icon prompt: `forensic notebook page with subtle face mesh and one evidence pin, careful media provenance and human review, calm geometric flat vector, dark ink, cyan verification mark, no scary face, no text, transparent background`.

Diagram: media file → metadata extraction → signal analysis → evidence timeline → human review → cautious conclusion.
